# 🍔 Online Food Ordering Website

A modern, responsive, and user-friendly **Online Food Ordering Website** developed using HTML, CSS, and JavaScript. This project provides a simple food-ordering experience with a professional dark-themed interface.

## 🚀 Features

- 🏠 Modern and professional homepage.
- 🍕 Browse different food items.
- 🔍 Search food items.
- 📂 Food categories and filtering.
- 🛒 Add food items to cart.
- ➕ Increase or decrease item quantities.
- 💰 Automatic total price calculation.
- 📱 Responsive design for mobile and desktop.
- 🎨 Professional black and dark-themed UI.
- ⚡ Interactive functionality using JavaScript.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Functionality and interactivity |

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website and its features.

## 🎯 Project Objective

The main objective of this project is to develop a frontend-based online food ordering platform that demonstrates the practical implementation of HTML, CSS, and JavaScript.

It helps demonstrate fundamental web development concepts, including DOM manipulation, event handling, responsive layouts, and dynamic content updates.
